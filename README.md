# ASTRA

**Autonomous Stellar Targeting Remote-access Apparatus**

Репозиторий проекта **StarTracker** — автоматизированного лазерного звёздного трекера, который наводит зелёный лазер (532 нм, 5 мВт) на любую звезду, планету или иной небесный объект по команде из Telegram-бота.

> Проект выполняется в рамках курса «Введение в цифровое производство. Практикум цифрового производства», ФАКТ МФТИ, Долгопрудный, 2026.

## О проекте

Устройство на двухосной поворотной платформе определяет своё положение и ориентацию, рассчитывает положение небесного тела и наводит на него лазер. Управление — через Telegram-бот по Wi-Fi. Вся логика выполняется на одном микроконтроллере ESP32.

**Ключевые характеристики**

| Параметр | Значение |
|---|---|
| Диапазон азимута | 360° непрерывно |
| Диапазон возвышения | 360° непрерывно |
| Точность наведения | 0.5–2° |
| Лазер | зелёный 532 нм, 5 мВт, класс 3R |
| Управление | Telegram-бот |
| Автономность | 3 часа |
| Корпус | 3D-печать PLA/PETG + лазерная резка (фанера/акрил) |

**Элементная база:** ESP32, 2× TMC2209 StepStick, RTC DS3231, GPS Neoway G7A, IMU BMI160, магнитометр GY-511, 2× NEMA17, 2× токосъёмное кольцо (slip ring ∅12 мм, 6 каналов), 2× Li-Ion LP385590 (2300 мАч, 3S), DC-DC MP1584, лазерный модуль 5 мВт (TTL), MOSFET IRLZ44N, датчики Холла A3144E на LM393.

---

## Принцип работы

1. GPS и RTC дают положение установки и время UTC.
2. BMI160 измеряет наклон основания (крен и тангаж).
3. Магнитометр определяет направление нуля монтировки относительно севера (с поправкой на магнитное склонение).
4. По имени объекта рассчитываются его азимут и высота над горизонтом (Astronomy Engine, для звёзд — собственный каталог).
5. Углы переводятся в систему монтировки и отправляются на моторы.
6. Лазер включается только когда цель достигнута и все данные достоверны.

## Безопасность лазера

- после `laser_init` лазер выключен;
- включается только при `status == Ok`, достигнутой цели и достоверных данных датчиков;
- любая потеря данных выключает лазер;
- вторая линия защиты — автоотключение по таймеру `LASER_MAX_ON_MS` внутри `laser.cpp`.

## Сборка и запуск

1. Установить VS Code и расширение PlatformIO IDE, открыть папку `firmware`.
2. Скопировать `firmware/src/secrets.example.h` в `firmware/src/secrets.h`
   и вписать данные Wi-Fi и токен бота.
3. Заполнить значения в `firmware/src/config.h` (пины, механика, склонение).
4. Собрать (`pio run` или кнопка Build) и прошить ESP32.
