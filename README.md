# ASTRA

**Autonomous Stellar Targeting Remote-access Apparatus**

Репозиторий проекта **StarTracker** — автоматизированного лазерного звёздного трекера, который наводит зелёный лазер (532 нм, 5 мВт) на любую звезду, планету или иной небесный объект по команде из Telegram-бота.

> Проект выполняется в рамках курса «Введение в цифровое производство. Практикум цифрового производства», ФАКТ МФТИ, Долгопрудный, 2026.

## О проекте

Устройство на двухосной поворотной платформе определяет своё положение и ориентацию, рассчитывает положение небесного тела и наводит на него лазер. Управление — через Telegram-бот по Wi-Fi.

**Ключевые характеристики**

| Параметр | Значение |
|---|---|
| Диапазон азимута | 360° непрерывно |
| Диапазон возвышения | 360° непрерывно  |
| Точность наведения | 0.5–2° |
| Лазер | зелёный 532 нм, 5 мВт, класс 3R |
| Управление | Telegram-бот |
| Автономность | 3 часа |
| Корпус | 3D-печать PLA/PETG + лазерная резка (фанера/акрил) |

**Элементная база:** Arduino Uno, ESP32, 2× TMC2209 StepStick, RTC DS3231, GPS Neoway G7A, IMU BMI160, магнитометр GY-511, 2× NEMA17, 2× токосъёмное кольцо (slip ring ∅12 мм, 6 каналов), 2× Li-Ion LP385590 (2300 мАч, 3S), DC-DC MP1584, лазерный модуль 520 нм 5 мВт (TTL), MOSFET IRLZ44N, датчики Холла A3144E на LM393.

| **Источники** | Ссылки и заметки, использованные при проектировании. |
