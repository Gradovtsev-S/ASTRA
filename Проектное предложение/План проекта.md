# StarTracker — Итоговый план реализации

---

## Концепция устройства

**StarTracker** — автоматизированный лазерный звёздный трекер на двухосной монтировке.
Устройство наводит зелёный лазер (5 мВт) на любую звезду, планету или небесный объект
по выбору пользователя через Telegram-бот.

---

## Конструкция (финальный вариант)

### Форм-фактор
Цилиндрический корпус (~150×150×190 мм, масса ~1.1–1.3 кг) на круглом основании
(∅300 мм). Внешне напоминает PTZ-камеру / прожектор на поворотной платформе.

### Две оси вращения

**Ось азимута (Z) — нижнее основание:**
- Диапазон: 360° непрерывно
- Привод: NEMA17 + червячная пара 1:40 (самоторможение, не нужен удерживающий ток)
- Slip Ring #1 в центре основания — передаёт питание и сигналы наверх при любом угле

**Ось возвышения (Y) — горизонтальная ось U-рамки:**
- Диапазон: 360° непрерывно (цилиндр делает «сальто» через зенит)
- Привод: NEMA17 + червячная пара 1:40
- Slip Ring #2 в левой опоре — передаёт питание и сигнал к лазеру
- При переходе за 90° (зенит): платформа разворачивается на 180°, лазер идёт «за голову»

### Внутренняя компоновка цилиндра
| Компонент | Позиция | Примечание |
|---|---|---|
| Лазерный модуль 5 мВт | Передняя стенка | TTL-управление через MOSFET IRLZ44N |
| ESP32 + собственная PCB | Центр | Wi-Fi, управление всей системой |
| АКБ 3S Li-Ion 3000 мАч | Нижняя часть | ~3 часа автономной работы |
| GPS NEO-6M | Верхняя часть | Антенна выведена наружу или в крышку |
| IMU MPU-6050 | Рядом с PCB | I2C, коррекция наклона основания |
| RTC DS3231 | На PCB | Точное время при потере GPS |
| DC-DC конвертер | На PCB | 11.1В → 5В и 3.3В |

### U-рамка
Алюминий или PETG-печать. Две вертикальные стойки + поперечина сверху. В стойках —
подшипники оси возвышения. Крепится к поворотной платформе болтами.

### Корпус
- Цилиндр и основание: PLA/PETG, 3D-печать
- Элементы жёсткости: лазерная резка из фанеры 4 мм или акрила
- Крышка цилиндра: съёмная, на защёлках — для доступа к электронике

## Схема электрических соединений

### Питание (три уровня)
```
АКБ 3S Li-Ion (11.1В)
├── TMC2209 #1 VM (12В) — мотор азимута
├── TMC2209 #2 VM (12В) — мотор возвышения
└── DC-DC MP1584 → 5В
    ├── ESP32 (VIN)
    ├── Лазер (через MOSFET)
    └── ESP32 3V3 pin → MPU-6050, DS3231, датчики Холла
```

### Распиновка ESP32
| GPIO | Функция | Куда |
|---|---|---|
| GPIO16 | UART2 RX | GPS NEO-6M TX |
| GPIO17 | UART2 TX | GPS NEO-6M RX |
| GPIO21 | I2C SDA | MPU-6050 + DS3231 |
| GPIO22 | I2C SCL | MPU-6050 + DS3231 |
| GPIO2 | STEP | TMC2209 #1 (азимут) |
| GPIO4 | DIR | TMC2209 #1 (азимут) |
| GPIO5 | EN | TMC2209 #1 (азимут) |
| GPIO18 | STEP | TMC2209 #2 (возвышение) |
| GPIO19 | DIR | TMC2209 #2 (возвышение) |
| GPIO23 | EN | TMC2209 #2 (возвышение) |
| GPIO1 | UART0 TX | TMC2209 #1 и #2 PDN_UART (один провод, разные адреса) |
| GPIO25 | PWM/GPIO | Gate MOSFET IRLZ44N (лазер) |
| GPIO34 | Input | Датчик Холла — ноль азимута |
| GPIO35 | Input | Датчик Холла — ноль возвышения |

### Управление лазером
```
GPIO25 → резистор 1 кОм → Gate IRLZ44N
Source IRLZ44N → GND
Drain IRLZ44N → GND лазера
+5В → VCC лазера
```

## Математика и алгоритмы

### Астрорасчёт (библиотека Astronomy Engine, C)
```c
// Планеты:
astro_time_t t = Astronomy_MakeTime(year, month, day, hour, min, sec); // UTC!
astro_observer_t obs = Astronomy_MakeObserver(lat, lon, elev);
astro_equatorial_t eq = Astronomy_Equator(BODY_JUPITER, &t, &obs,
                                           EQUATOR_OF_DATE, ABERRATION);
astro_horizon_t hor = Astronomy_Horizon(&t, &obs, eq.ra, eq.dec, REFRACTION_NORMAL);
double az  = hor.azimuth;   // 0–360°, от севера
double alt = hor.altitude;  // градусы над горизонтом

// Звёзды из каталога:
astro_horizon_t hor = Astronomy_Horizon(&t, &obs,
    18.615,  // RA в часах (Вега)
    38.783,  // Dec в градусах
    REFRACTION_NORMAL);
```

### Коррекция наклона (IMU MPU-6050)
```c
// Углы наклона из акселерометра
float roll  = atan2(ay, az) * 180.0 / M_PI;
float pitch = atan2(-ax, sqrt(ay*ay + az*az)) * 180.0 / M_PI;

// Complementary filter (каждые 10 мс)
roll  = 0.98 * (roll  + gx * 0.01) + 0.02 * atan2(ay, az) * 180.0 / M_PI;
pitch = 0.98 * (pitch + gy * 0.01) + 0.02 * atan2(-ax, ...) * 180.0 / M_PI;

// Поворот вектора для компенсации наклона
double x = cos(alt_r) * sin(az_r);
double y = cos(alt_r) * cos(az_r);
double z = sin(alt_r);
// ... вращение через матрицы крена и тангажа ...
double az_corr  = atan2(x2, y1) * 180.0 / M_PI;
double alt_corr = asin(z2)      * 180.0 / M_PI;
```

### Логика 360° по возвышению
```c
// Если объект «за зенитом» — цилиндр делает сальто
if (alt_target > 90.0) {
    alt_motor = 180.0 - alt_target; // лазер смотрит назад
    az_motor  = az_target + 180.0;  // платформа разворачивается
    if (az_motor >= 360.0) az_motor -= 360.0;
} else {
    alt_motor = alt_target;
    az_motor  = az_target;
}
```

### Перевод углов в шаги моторов
```c
// NEMA17 (200 шаг/об) + червяк 1:40 + микрошаг ×16
// Итого: 200 × 40 × 16 = 128 000 шагов/оборот
// Разрешение: 360° / 128000 = 0.0028°/шаг

int az_steps  = (az_motor  / 360.0) * 128000;
int alt_steps = (alt_motor / 360.0) * 128000;
stepper_az.moveTo(az_steps);
stepper_alt.moveTo(alt_steps);
```

## Поэтапный план реализации

### Этап 1 — Компоненты и тестовый стенд (4–5 недель)
- [ ] Заказать: ESP32, NEO-6M, MPU-6050, DS3231, 2× NEMA17, 2× TMC2209, IRLZ44N, лазер 5 мВт TTL, 2× slip ring (∅12–22 мм), подшипники, АКБ 3S
- [ ] Собрать на breadboard: ESP32 + IMU + GPS
- [ ] Проверить библиотеку Astronomy Engine — точность расчётов по известным объектам
- [ ] Написать базовый complementary filter для IMU
- [ ] Проверить управление лазером через MOSFET

### Этап 2 — Механика (4–5 недель)
- [ ] CAD-модель в Fusion 360 / FreeCAD:
  - круглое основание с червячной парой азимута и slip ring #1
  - U-рамка с подшипниками и slip ring #2 на оси возвышения
  - цилиндрический корпус с креплением под ось возвышения
- [ ] 3D-печать деталей (PLA для прототипа, PETG для финала)
- [ ] Лазерная резка жёстких элементов
- [ ] Сборка и проверка плавности хода обеих осей
- [ ] Проверка самоторможения червячных пар

### Этап 3 — Электроника (3–4 недели)
- [ ] Схема в KiCad: ESP32 + 2× TMC2209 + GPS + IMU + RTC + MOSFET + DC-DC
- [ ] Развести PCB (2-слойная, ~80×60 мм)
- [ ] Заказать изготовление платы (JLCPCB / PCBWay)
- [ ] Пайка и проверка
- [ ] Интеграция slip ring в обе оси, прокладка кабелей

### Этап 4 — Прошивка (5–6 недель)
- [ ] Инициализация периферии (GPS, IMU, моторы, лазер)
- [ ] Процедура калибровки нуля (уход на концевые выключатели Холла)
- [ ] Процедура калибровки IMU при включении (500 замеров, вычет bias)
- [ ] Астрорасчёты (Astronomy Engine) + коррекция наклона
- [ ] Управление моторами (AccelStepper / TMCStepper)
- [ ] Telegram-бот: `/find <объект>`, `/track`, `/stop`, `/calibrate`, `/status`
- [ ] Режим слежения: пересчёт позиции каждые 10 с

### Этап 5 — Интеграция и тестирование (3–4 недели)
- [ ] Сборка полного прототипа
- [ ] Дневные тесты: наведение на Луну, Солнце (с фильтром!), яркие планеты
- [ ] Ночные тесты: проверка точности по известным звёздам
- [ ] Калибровка star alignment (выравнивание по 2–3 звёздам для устранения систематики)
- [ ] Измерение реальной точности наведения

## Ключевые риски и митигация

| Риск | Митигация |
|---|---|
| Люфт в червячной паре → ошибка наведения | Двусторонняя выборка люфта, подходить к цели всегда с одной стороны |
| Дрейф IMU при долгой работе | Complementary filter + периодическая рекалибровка |
| Закрутка кабелей при 360° ALT | Slip Ring #2 на оси возвышения |
| GPS не берёт сигнал в помещении | Ручной ввод координат как fallback через Telegram-бот |
| Нагрев TMC2209 | StealthChop режим + снижение тока удержания до 30% при простое |
| Лазер не попадает в цель у зенита | Логика 360° ALT: сальто + разворот платформы на 180° |
