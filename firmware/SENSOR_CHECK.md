# Стендовая проверка датчиков ASTRA

## Сборка без платы

Из каталога `firmware` выполните `bash test/native/run.sh` и
`pio run -e esp32 -e board_diagnostics`. Эти команды собирают тесты и прошивку.

## Проверка на ESP32

1. Оставьте питание моторов и лазера отключённым. Проверьте общую землю и
   совместимость сигнальных уровней GPS и выходов Холла с входами ESP32.
2. Для сырого I²C-теста загрузите окружение `board_diagnostics` и откройте
   монитор на 115200 бод. По стендовому тесту SDA = GPIO21, SCL = GPIO22,
   ADXL345 = `0x53`, HMC5883L = `0x1E`. В покое норма ускорения должна быть
   близка к 1 g. При повороте меняются компоненты поля. Угол XY на этом этапе
   служит диагностикой магнитометра.
3. Закрепите оба датчика на неподвижном основании. Оси монтировки образуют
   правую систему: X вперёд вдоль az=0, Y вправо, Z вниз. Для каждого датчика
   отдельно заполните `ADXL_MOUNT_AXES` и `HMC_MOUNT_AXES` в `src/config.h`.
   Значение `{2, -1, 3}` означает X основания = +Y чипа, Y основания = −X чипа,
   Z основания = +Z чипа. У горизонтального основания ожидается примерно
   `(0, 0, -1) g` в этих осях. Подъём передней части даёт положительный
   pitch, опускание правой стороны даёт положительный roll.
4. Внесите проверенные GPIO датчиков Холла, уровень срабатывания, GPIO RX
   и скорость NMEA для G7A. TX оставьте `-1` при чтении GPS без команд.
   Драйвер Холла использует вход без внутренней подтяжки. Проверьте стабильный
   уровень покоя и переход при поднесении магнита на каждой оси отдельно.
   В основной прошивке поля Холла идут в порядке сырой уровень, активность,
   достоверность. Для смены стабильного состояния нужен уровень от 20 мс.
5. Загрузите окружение `esp32`. После фиксации GPS проверяйте признаки
   `pos=1 utc=1`. Позиция и высота берутся из GGA, дата и UTC из RMC.
   Остановите NMEA и проверьте сброс признаков примерно через 3 секунды.
   С UTC и валидной ориентацией монитор печатает диагностическую цель Moon.
6. Внесите местное склонение в `MAG_DECLINATION_DEG` со знаком плюс к востоку.
   Проверьте азимут по известному направлению и повторите измерение при наклоне
   основания. `cal=0` означает, что магнитная калибровка ещё впереди.
   Остаточную ошибку измерьте после окончательной установки оборудования.

## Переход к TMC2209

После стендовой проверки зафиксируйте GPIO STEP/DIR/EN, полярность DIR,
микрошаг, передаточные отношения, пределы хода и механические углы
срабатывания Холла. Первым этапом проверьте одиночную ось на малой скорости
с остановкой по тайм-ауту поиска нуля. Затем свяжите координаты наведения
с подтверждённым нулём каждой оси. Шкала высоты для наведения идёт от
0° вниз через 90° на горизонте до 180° в зените. API моторов сохраняет
свой диапазон до 360°, указанный в `motors.h`.
