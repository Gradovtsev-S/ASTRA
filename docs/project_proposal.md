## Цель проекта

Создать автоматизированное устройство для наведения лазерного указателя (5 мВт, 532 нм) на любую звезду, планету или иной небесный объект по выбору пользователя, обеспечивающее полный охват небосвода по азимуту и возвышению (360° по каждой оси без мёртвых зон), автономную работу не менее 3 часов и точность наведения 0.5–2° после калибровки по звёздам, с управлением через Telegram-бот по Wi-Fi.

---

## Описание функционала

Компактный звёздный трекер на двухосной поворотной платформе. Устройство получает данные о местоположении пользователя через GPS-модуль, определяет ориентацию относительно горизонта при помощи гироскопа и акселерометра, и на основе астрономических расчётов наводит лазер на любой выбранный небесный объект.

### Основные функции

- Автоматическое определение координат пользователя (GPS NEO-6M)
- Определение угла наклона и ориентации устройства (IMU MPU-6050)
- Расчёт положения небесных тел в реальном времени (библиотека Astronomy Engine, C)
- Наведение лазера на выбранный объект по двум осям (азимут + возвышение, 360° каждая)
- Управление через Telegram-бот по Wi-Fi
- Калибровка устройства перед использованием (датчики Холла, процедура star alignment)

### Дополнительный функционал

- Режим автоматического сопровождения объекта (пересчёт позиции каждые 10 с)
- Встроенный каталог ~200 объектов во flash ESP32 + Yale Bright Star Catalog (9110 звёзд) в SPIFFS
- Ручной ввод координат как fallback при отсутствии GPS-сигнала
- RTC DS3231 для точного хранения времени при потере GPS

## Конструкция

### Форм-фактор
Цилиндрический корпус (~150×150×190 мм) на круглом основании (∅220 мм), установленный в U-рамку на поворотной платформе. Внешне напоминает PTZ-камеру на поворотной платформе.

### Две оси вращения

**Ось азимута (Z) — нижнее основание:**
- Диапазон: 360° непрерывно
- Привод: NEMA17 + червячная пара 1:40 (самоторможение)
- Slip Ring #1 в центре основания — передаёт питание и сигналы при любом угле

**Ось возвышения (Y) — горизонтальная ось U-рамки:**
- Диапазон: 360° непрерывно (цилиндр делает «сальто» через зенит)
- Привод: NEMA17 + червячная пара 1:40
- Slip Ring #2 в левой опоре — передаёт питание и сигнал к лазеру
- При переходе за 90° (зенит): платформа разворачивается на 180°, лазер идёт «за голову»

## Задачи проекта

1. Выбор элементной базы и архитектуры системы
2. Разработка CAD-моделей корпуса и поворотной платформы (SolidWorks)
3. Проектирование механизма наведения лазера (двухосная монтировка, червячные передачи)
4. Создание электронной схемы устройства
5. Разработка собственной печатной платы (KiCad, JLCPCB)
6. Интеграция GPS-модуля, гироскопа и управляющего контроллера
7. Разработка прошивки микроконтроллера (Arduino/ESP-IDF, Astronomy Engine)
8. Реализация Telegram-бота (`/find`, `/track`, `/stop`, `/calibrate`, `/status`)
9. Производство деталей методом 3D-печати и лазерной резки
10. Сборка и тестирование устройства
11. Калибровка системы и проверка точности наведения (star alignment по 2–3 звёздам)

## Анализ существующих аналогов

### 1. Celestron StarSense Explorer
Система использует смартфон для определения положения звёздного неба и помощи в наведении телескопа.

**Преимущества:** удобство использования, автоматический поиск объектов.  
**Недостатки:** высокая стоимость, необходимость использования телескопа, отсутствие лазерного наведения.  
https://www.celestron.com/pages/starsense-explorer

### 2. DIY OpenAstroTracker
Open-source проект автоматизированного трекера для астрофотографии на Arduino.

**Преимущества:** открытый исходный код, возможность самостоятельной сборки.  
**Недостатки:** сложность настройки, отсутствие удобного пользовательского интерфейса, не предназначен для лазерного наведения.  
https://openastrotech.com

**Отличие StarTracker от аналогов:** автономная работа с GPS и гироскопической системой, удобное управление через Telegram-бот, полный охват небосвода без мёртвых зон по обеим осям, компактный корпус с лазерным указателем вместо телескопической оптики.

## Эскиз проекта

Устройство состоит из цилиндрического корпуса с лазерным модулем, установленного в U-рамку на двухосной поворотной платформе. Нижнее основание содержит привод азимута и аккумулятор, U-рамка несёт привод возвышения и оба slip ring для непрерывного вращения по обеим осям.

*(Эскиз прилагается отдельным файлом)*
